# Altis-Biblioteca-Frontend

## Technology Stack

- Vue.js
- JavaScript
- HTML5
- CSS3
- Docker

## Prerequisites

## Estrutura de páginas

- `pages/auth/`: login, cadastro e recuperação de senha.
- `pages/admin/`: dashboard e telas de gerenciamento de usuários, editoras, livros e empréstimos.
- `pages/locatario/`: espaço reservado para as telas do locatário.
- `css/auth/`: estilos das telas de autenticação.
- `css/admin/`: estilos das telas administrativas.
- `css/shared/`: estilos compartilhados, como a navegação.
- `js/auth/`: scripts das telas de autenticação.
- `js/admin/`: scripts das telas administrativas.
- `js/shared/`: scripts compartilhados, como navegação e máscaras.
- `assets/`: imagens e ícones compartilhados entre as áreas.

## Acesso

- Administrador: `admin@admin.com` com a senha `12345678`.
- A conta administrativa é fixa e não pode ser criada pelo cadastro comum.
- Usuários cadastrados com seus dados de locatário são direcionados para `pages/locatario/`.
